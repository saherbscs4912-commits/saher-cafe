# Bean & Brew Café ☕

Bean & Brew Café is a simple and interactive café website built using **HTML, CSS, and JavaScript**. The website provides information about the café, menu items, and contact/reservation options with a clean and user-friendly design.

## Features

- Café home and about sections
- Menu with category filtering
- Interactive menu table
- Light/Dark mode
- Order total calculator
- Age and discount calculation
- Read More/Read Less functionality
- Contact/reservation form
- Dynamic café opening/closing status
- Special notes character counter

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Bean-Brew-Cafe/
│
├── index.html
├── styles.css
└── script.js
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the Bean & Brew Café website.

## Purpose

This project was created to practice **HTML structure, CSS styling, and JavaScript interactivity** by developing a functional café website.
